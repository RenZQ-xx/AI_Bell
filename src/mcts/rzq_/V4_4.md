# v4.4 六 bucket expansion 消融

入口 `run_class8_v4_4.py` 继承 v4.3，只将 compatibility-richness expansion 的 bucket 数从2恢复为6。

- bucket 0：按 compatibility-richness prior 抽样。
- bucket 1–5：在未展开动作中均匀随机抽样。

因此，prior 类型仍是 compatibility-richness；变化是 prior bucket 从约二分之一的扩展降为约六分之一，同时六 bucket 的初始配额会使节点早期允许展开更多动作。selection 仍使用原始父边Q、真实节点visits，最低访问保障为1。其余设置与v4.3一致。

```bash
src/mcts/rzq_/.venv/bin/python src/mcts/rzq_/run_class8_v4_4.py
src/mcts/rzq_/.venv/bin/python src/mcts/rzq_/compare_v4_variants.py --include-v44
```

默认输出 `runs/class8_v4_4_300_trace/`；五版比较输出 `runs/v4_v4_1_v4_2_v4_3_v4_4_comparison.md` 和同名JSON。

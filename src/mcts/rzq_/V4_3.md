# v4.3 原始父边 Q 消融

入口 `run_class8_v4_3.py` 继承 v4.2 factory，只设置 `ucb_normalize_edge_survival_q=False`。selection 使用原始父边 survival Q，而非 min-max 归一化值。

最低子节点 visits 仍为1；探索项仍使用真实父子节点 visits、compatibility-richness prior 和常数1.4。flat closure、普通 block 动作、无对称合并、双bucket、rollout、预发现集合与 seed 全部沿用 v4.2。保留此前所有版本入口和结果。

从仓库根目录运行（WSL）：

```bash
src/mcts/rzq_/.venv/bin/python src/mcts/rzq_/run_class8_v4_3.py
src/mcts/rzq_/.venv/bin/python src/mcts/rzq_/compare_v4_variants.py --include-v43
```

默认300轮、seed=20288754。结果写入 `runs/class8_v4_3_300_trace/`，四版对照写入 `runs/v4_v4_1_v4_2_v4_3_comparison.md` 和同名JSON。已存在的实验输出不会覆盖。

验证包含逐个 selection 候选检查 `exploitation == edge_survival_q`；trace 中仍可能保留 normalized_q 诊断字段，该字段不参与本版本 selection 的价值项。

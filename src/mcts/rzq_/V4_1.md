# v4.1 对照版本

入口：`run_class8_v4_1.py`。基于当前 `v3_task_factory`，仅关闭 action 对称分类和对称节点复用/合并。

| 设置 | v4.1 |
|---|---|
| class8 分块 | 原有 40 个 orbit blocks |
| action 分类 | 关闭，保留全部未选 block |
| 节点 flat closure | 开启 |
| 对称节点复用/合并 | 关闭 |
| 完全相同闭包状态复用 | 开启，与普通状态字典语义一致 |
| expansion bucket | compatibility-richness prior / 均匀随机，两 bucket |
| expansion prior | 对所有普通动作计算 compatibility-richness softmax |
| 最低访问保障 | child.visits >= 5 |
| selection 价值 | 父边 survival Q，父节点内 min-max 归一化；同值取 0.5 |
| selection 探索 | 真实 parent.visits / child.visits，常数 1.4 |
| rollout | 保留当前公共 top-k 边界同分均匀抽样修复 |

历史 v3 的已保存 300 轮 trace 尚未包含 rollout 同分修复；需要严格隔离 action 分类/对称合并的影响时，应使用当前 v3 入口重跑对照，不应直接把旧 trace 视为仅这两处不同。

本版本沿用旧实验的预发现集合、seed 和固定 300 次 step 调用，不启用拟议 v11/v12 的新集合、无新发现 300 轮停止或重启机制。运行命令（仓库根目录、WSL）：

```bash
src/mcts/rzq_/.venv/bin/python src/mcts/rzq_/run_class8_v4_1.py
```

默认输出 `runs/class8_v4_1_300_trace/`，已存在时拒绝覆盖；可通过 `--output` 指定新目录。

实现中 `RZQNodeManager(symmetry_dedup=False)` 保持 flat closure，查找键使用实际闭包状态，所有坐标映射为恒等映射，复用事件记为 `exact_node_reuse`，不会记为对称复用。默认参数仍为 True，不改变 v3 行为。

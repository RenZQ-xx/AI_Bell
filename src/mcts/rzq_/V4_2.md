# v4.2 最低访问保障消融

`run_class8_v4_2.py` 直接继承 v4.1 factory，仅将 `ucb_min_action_visits` 从5改为1，保留 v4.1 原入口与结果。

分块、预发现集合、seed、flat closure、普通动作、完全相同状态复用、无对称合并、compatibility-richness prior、双bucket、归一化父边Q、真实节点访问探索项和 rollout 均不变。每个新展开子节点已通过回传获得一次 visit，因此本实验预计没有 minimum_visits 强制选择。

从仓库根目录运行（WSL）：

```bash
src/mcts/rzq_/.venv/bin/python src/mcts/rzq_/run_class8_v4_2.py
src/mcts/rzq_/.venv/bin/python src/mcts/rzq_/compare_v4_variants.py
```

默认运行300轮，输出 `runs/class8_v4_2_300_trace/`。入口拒绝覆盖已有输出，可用 `--output` 指定其他目录。比较结果为 `runs/v4_v4_1_v4_2_comparison.md` 和同名 JSON。

本实验不使用拟议 v11/v12 的新预发现集合或预算重启机制。

## 如何阅读路径

- `A`：Filler/add，加入一个 block 或 orbit union；`D`：Corrector/remove；`W`：Corrector/rewrite。
- `(+n)`、`(-n)`、`(-r+a)` 分别表示加入、删除、rewrite 删除/加入的顶点数。
- 方括号是该 pattern 内的 `orbit_indices`。rewrite 是支持集宏变换，结果中通常没有单独的 orbit 索引。
- 来源：`T=atlas`，`O=observed_stabilizer`，`F=facet_repartition`，`X=facet_external_exit`。
- pattern 缩写：`C*/H-*` 省略 `BFS322-`；`E:*` 代表 `EMBED-*`；`O:*` 代表 `OBS-*`。
- `!` 标出 `corrector_novelty_credit_events` 中分到该 class 新颖性奖励的 Corrector 动作；若有多个 `!`，10 分奖励按这些祖先 Corrector 分摊。
- `path` 是该 iteration 从 root 到首次命中终端的完整动作链，包含树策略段和 rollout 段。结果 JSON 只序列化了 action，没有保存每一步的 `is_tree_edge`，因此无法从本次产物可靠恢复两段的精确分界。`policy` 是该 iteration 使用的 rollout policy。
